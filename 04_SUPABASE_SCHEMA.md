# SUPABASE DATABASE

## Bảng leaderboard

Tạo file `supabase-schema.sql`.

```sql
create table if not exists public.leaderboard (
  id bigint generated by default as identity primary key,
  nickname text not null,
  score integer not null default 0,
  level integer not null default 1,
  coins integer not null default 0,
  created_at timestamptz not null default now()
);
```

## Constraints

```sql
alter table public.leaderboard
add constraint nickname_length
check (char_length(nickname) between 2 and 15);

alter table public.leaderboard
add constraint score_nonnegative
check (score >= 0);

alter table public.leaderboard
add constraint level_valid
check (level between 1 and 100);

alter table public.leaderboard
add constraint coins_nonnegative
check (coins >= 0);
```

## Index

```sql
create index if not exists leaderboard_score_idx
on public.leaderboard(score desc);
```

## RLS

Bật RLS:

```sql
alter table public.leaderboard enable row level security;
```

Cho phép đọc leaderboard:

```sql
create policy "Public can read leaderboard"
on public.leaderboard
for select
using (true);
```

Không tự động cho phép anonymous insert trong production nếu chưa cân nhắc abuse.

Nếu MVP cần anonymous insert, tạo policy insert có kiểm soát và ghi rõ đây chỉ là MVP.

## Recommended production

Production nên dùng:
- Supabase Edge Function.
- Server-side validation.
- Rate limiting.
- Anti-cheat.
- Không để service_role key trong frontend.

## Frontend keys

Chỉ sử dụng:
- Supabase project URL.
- anon/public key.

TUYỆT ĐỐI không đưa `service_role` key vào `config.js`.

## Query Top 10

```javascript
supabase
  .from("leaderboard")
  .select("nickname, score, level, coins, created_at")
  .order("score", { ascending: false })
  .limit(10);
```
